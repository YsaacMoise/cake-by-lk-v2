# Cake by LK, version 2

Deuxième version du site de Cake by LK, construite le 16/11/2026 à partir du prototype de référence
du 13/11/2026, avec les photos des gâteaux de LK (toutes validées par LK, selon YKM, le 16/11/2026).

- En ligne : https://ysaacmoise.github.io/cake-by-lk-v2/ (site de test, non référencé : noindex et robots.txt).
- Dépôt : https://github.com/YsaacMoise/cake-by-lk-v2 ; publication par GitHub Pages depuis la branche main.
- Le site actuel (dépôt cake-by-lk) n'est pas modifié.
- Aucune donnée envoyée : le message de commande est copié, puis collé par la cliente dans Instagram.
- Contrat de design : DESIGN.md. Faits : .gout/faits.json (hors ligne).
- Photos : traitées par .gout/style_nina.py (même étalonnage, recadrage serré 4:5, fond crème flou pour les gâteaux à thème),
  gâteau d'accueil par .gout/detourer.py et .gout/finir_detour.py. Grands formats sur le bureau : 16_Photos_style_V2.
- Page reconstruite par .gout/construire.py à partir de gabarit.html (la galerie est écrite par le script).
